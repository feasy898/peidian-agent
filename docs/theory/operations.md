# 运维决策域 · 阶段 a 理论卷

> 项目：peidian-agent 园区配电运维智能体
> 卷宗用途：园区配电 DSL 概念与仿真判据的现实依据；「正常营业与管理变化」事件生成器的蓝本
> 撰写日期：2026-10-02　|　撰写方式：种子条目逐条 WebSearch 检索 + WebFetch 实开来源核验
> 读者：电力专家。本文区分【标准条文】【企业制度】【工程惯例】三级依据；凡未能在官方渠道打开原文、仅经二手转引的条文一律加【待核】。

---

## 概述

运维决策域覆盖园区配电室（用户侧）日常运行的七类决策对象：**巡视、缺陷、报修抢修、保电、停电计划、交接班、定期试验与轮换**。与设备域不同，本域大部分事件不是设备故障，而是**按日历与制度周期触发的管理事件**——巡检到期、试验到期、保电任务下达、计划停电公告、交接班。因此本卷同时是事件生成器的蓝本：生成器的主要输入是各制度的**周期参数与判据**，而非物理模型。

**用户侧视角的依据层级**（本文贯穿使用）：

1. 【标准条文】国家标准、行业标准、法规规章的原文条款。用户侧园区直接受约束的是 GB/T 37136（用户侧运维规范）、GB/T 29328（重要电力用户配置）、DL/T 1102（配变运行）、《供电营业规则》（与电网企业的服务界面）等【R14】【R94】【R91】【R6】。
2. 【企业制度】电网企业内部管理规定/反措（国网变电运维管理规定、十八项反措、95598 办法、供电服务"十项承诺"）。它们约束的是供电企业而非用户，但**决定了园区与电网交互的服务水平**（报修到场时限、停电公告提前量、保电检查频次）——仿真界面层必须采用这组参数【R95】【R63】【R105】【R106】。
3. 【工程惯例】行业通行做法，无统一条文出处，各单位执行尺度不一（如柴发空载试机时长、缺陷消除时限）。DSL 中应作为**可配置默认值**而非硬判据。

## 核心机制与判据

### 1. 巡视制度

**巡视分类**。电网企业变电运维将巡视分为五类：例行巡视、全面巡视、专业巡视、熄灯巡视、特殊巡视，并按变电站类别规定例行巡视频次（一类站每天至少 1 次、二类站每 3 天至少 1 次、三类站每周不少于 1 次）【R105】【企业制度，待核原文】。用户侧园区配电室通常简化为止每周例行 + 每月全面【工程惯例】。

**熄灯巡视**。每周至少一次，利用夜间黑暗环境检查白天不可见的**放电闪光、电晕、过热发红**缺陷【R105】【企业制度，待核原文；频次与五分类法在多个二手来源一致】。这与种子"每周≥1 次查放电发热"吻合。

**配电变压器巡视频次**。DL/T 1102《配电变压器运行规程》规定配变巡视周期为**每月至少一次，每季至少进行一次夜间巡视**，特殊情况应增加巡视次数【R91】【R92】。该条文出自流传全文 5.1.2（2021 版现行，代替 DL/T 1102-2009；2021 版条文位置可能调整，【待核】官方全文）。适用范围：2021 版为 35kV 及以下、三相额定容量不超过 2500kVA 的配电变压器【R91】——园区配变基本都落在该范围内。

**特殊巡视触发条件**。DL/T 1102 规定在特定情形下应增加巡视频次【R92】；行业通行的触发清单为：恶劣天气（台风/暴雨/雷电/大雾/高温寒潮）、过负荷或超温运行、新投运与检修后、故障跳闸后、保电任务期间、法定节假日【工程惯例，触发清单各单位细则略有差异】。

**巡检项目清单**。GB/T 37136-2018《电力用户供配电设施运行维护规范》将用户侧设施的**巡视检查、试验检测、缺陷处理、更新改造**纳入统一技术基准【R94】【标准条文，经国家标准全文公开系统核验标准信息】。种子给出的项目清单（外观/异响/气味，油位油温或干变温控，开关柜带电显示，仪表指示，直流屏与蓄电池，继保信号，环境温湿度/水浸/烟感，红外测温）属上述基准下的典型项目集【工程惯例】。

**红外测温判据**。DL/T 664-2016《带电设备红外诊断应用规范》（2016-12-05 发布 / 2017-05-01 实施，现行）给出表面温度判断法、**相对温差判断法**、图像特征判断法与缺陷诊断判据【R102】。相对温差定义：

```
δ = (T₁ − T₂) / (T₁ − T₀) × 100%
```

其中 T₁ 为发热点最高温度、T₂ 为正常对应相温度、T₀ 为环境参考体温度。检索文本给出的判据量级：35%＜δ＜80% 判一般缺陷，δ≥80% 判严重缺陷（电流致热型）【R102】【判据数值出自检索摘要，建议建库前比对标准附录 H 原表【待核】】。另检索中出现疑似 2025 年新版信息，未获证实【待核】。

### 2. 缺陷管理

设备缺陷按对安全运行的威胁程度分为**危急、严重、一般**三级【R107】。通行消除时限：危急缺陷≤24h（立即处理）、严重缺陷≤72h、一般缺陷≤1 个月（结合检修计划消除）【R107】【工程惯例：时限值源自各单位缺陷管理办法，国标层面未见统一数值，DSL 中应作可配置参数】。缺陷闭环流程：发现→定级→上报→消缺→验收→归档，全流程留痕【工程惯例】。

### 3. 报修与抢修（95598 界面）

**业务流程**。客户报修经 95598 客服受理（记录户名/地址/电话/故障现象）→ 按产权分流 → 生成抢修工单下发属地 → 派工（反馈负责人/联系电话/出发时间）→ 到场处理 → 复电回单（用户签字确认）→ 归档 → 客服中心限时回访【R95】【R96】【R106】【流程为供电企业制度；产权分界（用户侧内部故障不属供电企业抢修范围）是园区模拟的关键界面规则【R96】】。

**到达现场时限**。国家电网供电服务"十项承诺"第二条：提供 24 小时电力故障报修服务，抢修人员到达现场时间一般不超过——**城区 45 分钟、农村 90 分钟、特殊边远地区 2 小时**（原文经政府网转载全文核验）【R95】。南方电网有同等承诺【R95，未见原文，待核】。

**回访**。工单回单完毕后国网客服中心在规定时限内回访客户【R106】【企业制度，原文未开，待核时限数值】。

### 4. 保电（重要电力用户管理）

**分级**。GB/T 29328-2018《重要电力用户供电电源及自备应急电源配置技术规范》（2018-12-28 发布 / 2019-07-01 实施，经国家标准全文公开系统核验）按供电可靠性要求与中断供电危害程度，将重要电力用户分为**特级、一级、二级和临时性**四类【R14】。地方实施细则可在国标基础上增设级别（如呼伦贝尔市办法增设"三级"，共五类）【R101】【已打开核验原文】。

**供电配置要求**。特级重要用户应采用多电源供电（三路独立电源、其中两路来自不同变电站）；一级至少双电源（取自两个独立变电站或同一变电站不同母线段）；二级至少双回路【R14】【条文号 6.2.2 出自标准 PDF 检索摘要，官方全文页仅核验标准信息，具体条文【待核】】。

**保电检查周期**。供电企业对**特级、一级重要客户每 3 个月至少检查 1 次，二级每 6 个月至少检查 1 次**，临时性重要客户按现场实际用电需要开展用电检查【R63】【出处为《国家电网有限公司十八项电网重大反事故措施（修订版）》第 5.2 条——注意这是**企业反措**而非国标条文；同一 PDF 已由安全规程域卷完成全文提取（R63），但其摘录清单未含 5.2 条逐字内容，5.2 表述仍待核】。

**自备应急电源运维**。国标要求自备应急电源定期进行**安全检查、预防性试验、启机（启动）试验和切换装置的切换试验**【R14】【R101】【R101 已打开地方政府文件核验原文，该文即转述国家规程规范要求；国标对应条文号（检索示 7.4.1）【待核】】。

**保电流程**。重大活动/重要时期保电通行四阶段：方案编制（运行方式、电源配置、应急预案）→ 隐患排查（用户侧受电设备专项检查）→ 保电实施（特巡与值班加密、抢修队伍前置、应急电源车/柴发待命）→ 总结归档【工程惯例】。保电期间核心判据是**零闪动**（保电对象母线不失压）【工程惯例】。

### 5. 停电计划管理

**提前公告义务**。供电设施**计划检修停电应提前 7 天通知用户或向社会公告**（"十项承诺"第三条原文：供电设施计划检修停电，提前 7 天向社会公告）【R95】【已核验】；《供电营业规则》同样规定计划检修提前 7 天、**临时检修提前 24 小时**通知重要用户或公告【R6】【R6 全文 PDF 已由业务经营域卷完成文本提取（其中计划检修提前 7 日已核）；临时检修提前 24 小时具体条文仍需在该全文中定位】。

**计划编审流程**。配网停电通行月度计划为主、周计划滚动补充：申请→（供电公司）月度平衡会审批→提前公告→执行→验收送电【工程惯例】。园区侧对应动作：收到公告后核对受影响馈线、安排负荷转移或启动双电源倒换、通知重要负荷。

**用户侧配套动作**。双电源用户应定期进行倒换试验并在电网预试停电前配合倒电；用户侧预防性试验需向电网申请停电配合【R101】【工程惯例】。

### 6. 交接班

DL/T 969《变电站运行导则》（DL/T 969-2005，2005-11-28 发布 / 2006-06-01 实施，适用于交流 35kV 及以上变电站及监控中心，现行）规定了变电运行值班人员设备运行、操作、异常及故障处理的行为准则，含运行值班与交接班要求【R97】【标准详情页已核验；具体交接班条款号【待核，全文 PDF 未打开】】。

通行交接内容清单（种子条目与检索一致）：**运行方式与负荷变化、未完结的操作票/工作票、设备异常与缺陷、继电保护及自动装置投退变更、工具仪表钥匙、上级指示与调度命令**【R97】【工程惯例，条目化清单各单位细则措辞不一】。两条纪律：交接双方核对无误、在记录上签字后方为完成；**交接班时发生事故（异常）应立即停止交接，由交班人员处理、接班人员协助**【R97】【R108】【R108 为卫健委后勤安全指南对 DL/T 969 的转引，原文页超时未打开【待核】】。**交接班过程中一般不进行倒闸操作**【工程惯例，未见统一条文】。

### 7. 定期试验与轮换

**柴油发电机组**。月度空载试机有行业先例：通信行业 YD/T 1970 系列《通信局（站）电源系统维护技术要求》（发电机组系统部分）要求**每月空载试机，冷启动/热启动各一次**【R104】【检索文本一致；具体部分号与年份未在官方渠道核验【待核】】。一般用户侧通行做法：每月空载试机 15~30 分钟，每季度带载试验一次并做功率突变检查【工程惯例】。

**UPS/直流蓄电池核容放电**。DL/T 724《电力系统用蓄电池直流电源装置运行与维护技术规程》规定蓄电池组的核对性放电要求：新安装或大修后应做全核对性放电，运行 6 年以后每年一次核对性放电【R99】【版本需注意：2000 版全文流通，检索显示 2021 版现行，具体条文号与周期表【待核】】。

**备自投（备用电源自动投入装置）切换试验**。DL/T 995-2016《继电保护和电网安全自动装置检验规程》规定继电保护与安全自动装置及其二次回路**各类检验的周期、内容及要求**，适用范围明确包含**用户**【R98】【已核验适用范围原文；备自投装置的具体全部检验周期数值（检索示"首检后每 6 年全部检验"为一般要求）【待核，需比对标准正文第 4 章检验周期表】】。

**轮换逻辑**。以上试验/轮换的共同结构是"周期 + 到期 + 记录"：DSL 中统一建模为周期任务，到期未做即产生管理事件（逾期告警）【工程惯例】。

## 常见异常与故障现象（本域典型事件）

本域非设备域，按事件生成器需要给出三类典型事件。每类事件在 DSL 中是"管理事件"，判据取自上文各节。

### A. 巡视发现类（由巡视任务产生，产出缺陷或告警）

| 事件 | 触发/判据 | 典型参数 |
|---|---|---|
| 红外测温超限 | 相对温差 δ 越限 | δ≥35% 一般、≥80% 严重【R102】 |
| 配变异常声响/异味 | 例行巡视感官项 | 夜巡更易发现放电声【R92】 |
| 渗漏油/油位偏低 | 油变巡视项 | 油位计刻度低于下限 |
| 干变温控器告警 | 温控显示超整定 | 绕组温度越限值（常见 100/130℃ 两级告警）【工程惯例】 |
| 直流屏绝缘下降/蓄电池落后 | 直流屏巡检、核容放电 | 单体电压低于整定、核容容量<80%【R99】 |
| 开关柜带电显示异常/柜内凝露 | 巡视+环境项 | 柜内湿度越限、加热器失效 |

### B. 服务与时限类（95598 界面产生，考核性判据）

| 事件 | 判据 |
|---|---|
| 报修工单到场超时 | 到场时长 > 城区 45 / 农村 90 / 边远 120 min【R95】 |
| 产权分界误派 | 用户内部故障误报电网抢修范围【R96】 |
| 复电未确认/回访不满 | 回单未经用户签字确认、回访发现抢修质量问题【R96】【R106】 |
| 计划停电公告未覆盖 | 公告提前量 < 7 天【R95】【R6】 |

| 事件 | 触发 | 生成时机 |
|---|---|---|

| 计划停电公告/执行 | 月度/周计划平衡通过【R95】【R6】 | 公告日、执行日 |
| 交接班异常交接 | 事故时停止交接、票单未清【R97】【R108】 | 每班次 |

| 保护定值/装置投退变更 | 调度指令下达 | 变更时刻，纳入交接班【R97】 |

## 对 DSL 与仿真的含义

以下把本域概念映射为可建模参数（建议字段名 + 量纲 + 取值域）。**周期与 SLA 参数全部是事件生成器与时间加速的驱动源**：仿真钟按日推进时，由这些周期字段生成任务事件，由 SLA 字段生成考核事件。

### 1. 巡视任务 PatrolTask

| 字段 | 量纲 | 取值域（建议默认） |
|---|---|---|
| patrol_type | enum | {routine 例行, comprehensive 全面, professional 专业, lights_out 熄灯, special 特殊}【R105】 |
| interval_days | 日 | 例行 1~30（配变月巡默认 30【R91】【R92】）；夜巡 90【R92】；熄灯 7【R105】 |
| night_window | bool | 熄灯/夜间巡视 = true |
| items | list[CheckItem] | 感官项/油位油温/带电显示/仪表/直流屏/继保信号/环境/红外【R94】 |
| due_date, completed_at | date, datetime | 逾期未完成 → 逾期事件 |

### 2. 红外判据 CheckItem（ir_*）

| 字段 | 量纲 | 取值域 |
|---|---|---|
| ir_delta_t_pct | %（相对温差） | 0~100；≥35 一般、≥80 严重【R102】 |
| ir_t1, ir_t2, ir_t0 | ℃ | 实测三温度 |
| defect_class | enum | {none, general, severe, critical}【R102】【R107】 |

### 3. 缺陷记录 DefectRecord

### 9. 仿真判据汇总（人机对比评分可直接引用）

1. **按期率**：巡检/试验/保电检查按期完成数 ÷ 应完成数（周期字段驱动）。
2. **时限符合率**：抢修到场、缺陷消除、停电公告提前量达标数 ÷ 总数（SLA 字段驱动）。
3. **闭环率**：缺陷 archived 比例、工单 archived+回访比例。
4. **保电零闪动**：保电时段保电对象母线失压次数 = 0。
5. **交接规范性**：票单未清交接、事故时段违规交接的扣分项。
6. **时间加速一致性**：所有周期按"每月≥1、每季≥1、每周≥1、每 3 个月≥1"的日历语义展开，加速 N 倍时事件按日历时刻重排而非简单缩放。
