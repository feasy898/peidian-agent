## 1. 概述

设备运行域覆盖园区配电系统一次设备与二次支撑系统的运行监视、判据与异常演化：

- **链路**：10kV 进线（双路或单路+柴发后备）→ 10kV 开关柜（环网柜/中置柜）→ 配电变压器（干变为主，1600kVA 级，工程常见容量序列 630/800/1000/1250/1600/2000 kVA，种子给定）→ 0.4kV 低压柜/母联 → PDU；
- **DER**：光伏并网、储能、充电桩、UPS、柴油发电机；
- **二次支撑**：直流操作电源（220V/110V）、温控器、局放带电检测、绝缘监测。

本域的三条建模主线：

1. **判据即参数**：所有阈值（电压偏差、谐波、温升、局放 dB、绝缘 kΩ、频率）都是 DSL 中的可配置参数，且每个阈值必须携带**来源类型标签**（国标条文 / 行标企标条文 / 政策反措 / 工程惯例 / 厂家默认）。本卷核实过程中已发现至少三处"种子数值与标准原文或现行版本不符"的情况（直流绝缘电阻口径、Q/GDW 11063 名称、二十五项反措版本），印证了来源标签的必要性。
2. **事件演化链**：隐患 → 异常 → 告警 → 事故 四阶段，与电力行业"设备缺陷分级管理"（危急/严重/一般）及反事故措施体系对应（见 2.7），是事件生成器的时间轴骨架。
3. **信息模型**：以 IEC 61850 的 Server→LD→LN→DO→DA 分层、stVal+品质位+时标三元组、缓冲/非缓冲报告、控制模型为遥测遥信口径的原型（见 2.8）。

## 2. 核心机制与判据

### 2.1 园区供电架构与拓扑

园区典型接线为 10kV 双路进线（或单路+柴发后备）经高压开关柜到配电变压器，降至 0.4kV 后经低压柜（含母联开关）分馈至 PDU；DER 经并网点接入低压或 10kV 母线。此为种子给定架构与工程通例，不涉具体标准条文。

中性点接地方式决定单相接地故障的行为（见 2.6）：10kV 配网属**中性点非有效接地**（不接地或经消弧线圈/谐振接地），发生单相接地时故障电流仅为电容电流，线电压仍对称，故允许短时带故障运行；GB/T 50064-2014 对接地方式选择给出电容电流准则（不大于 10A 可采用不接地方式，大于 10A 且需带故障运行时宜谐振接地）【R44】。

### 2.2 电能质量判据（四项国标，均【标准条文】）

1. **供电电压偏差**（GB/T 12325-2008，现行，2008-06-18 发布 / 2009-05-01 实施，经 openstd 实测确认）：
   - 35kV 及以上：正、负偏差绝对值之和不超过标称电压的 10%；
   - 10kV 及以下三相供电：±7%；
   - 220V 单相供电：+7% / -10%。
   【R31】
2. **公用电网谐波**（GB/T 14549-1993，仍现行）：电压总谐波畸变率（THDu）限值按电压等级分档——0.38kV ≤5%、6~10kV ≤4%、35~66kV ≤3%、110kV ≤2%（220kV 参照 110kV）。【R32】
3. **三相电压不平衡**（GB/T 15543-2008）：电网正常运行时公共连接点**负序电压不平衡度不超过 2%，短时不超过 4%**；每个用户引起的负序不平衡度一般允许 1.3%、短时 2.6%；低压系统零序暂不作规定但各相电压须满足 GB/T 12325。【R33】
4. **频率偏差**（GB/T 15945-2008）：正常运行条件下频率偏差限值 **±0.2Hz**；系统容量较小时可放宽至 ±0.5Hz。【R34】

**建模注意**：四项标准的限值均有配套的测量与取值方法（测量窗口、取值统计、合格率），DSL 判据不能只写限值常数，还应带上测量窗口与判稳时间字段；测量方法细节本卷未逐一核对原文，标注【待核-测量方法】。

### 2.3 温升与热判据

1. **开关柜温升**：GB/T 11022-2020《高压交流开关设备和控制设备标准的共用技术要求》（现行，2020-12-14 发布 / 2021-07-01 实施，代替 2011 版，经 openstd 实测确认）以**周围空气温度不超过 40℃**（日平均不超过 35℃）为正常使用条件基准，在"设计与结构"章以温升限值表规定触头与连接的分档限值。常被引用的分档值：裸铜触头 35K、镀银/镀镍触头 65K、螺栓连接裸铜 50K、镀锡触头 75K。【R35】【标准条文；**表 3 逐值未对照原文，写入 DSL 默认值前须核原文表 3——待核**】
2. **油浸变压器顶层油温**：DL/T 572-2021《电力变压器运行规程》表 1 给出额定电压下顶层油温一般限值：自然循环自冷/风冷（ONAN/ONAF）冷却介质 40℃ 时最高顶层油温 95℃；强迫油循环风冷（OFAF）85℃；强迫油循环水冷（OFWF）70℃；并规定自然循环冷却变压器顶层油温**一般不宜经常超过 85℃**。【R39】【标准条文；本卷未能打开规程原文页（gong123.com 拒连），数值取自检索摘要——待核】
3. **油浸变"报警 85℃ / 跳闸 105℃"**：常见工程整定惯例（85℃ 对应"不宜经常超过 85℃"的运行控制值，105℃ 为跳闸整定），**并非 DL/T 572 条文**，实际整定以制造厂技术条件与现场运行规程为准。【R39】【工程惯例——待核】
4. **干式变压器温控器四点整定**：F 级绝缘（极限 155℃）干变温控器出厂默认常见设定——**80℃ 关风机 / 100℃ 启风机 / 130℃ 超温报警 / 150℃ 超温跳闸**；H 级（180℃）取值相应上移。【R40】【工程惯例（厂家出厂默认），非标准条文；个别文章将该四点归因于 GB/T 6450 系温升标准，归因不可靠，未采信】

热机理（DSL 仿真需体现）：绕组/接头温升 = 负荷电流平方×电阻的热时间常数过程；接触电阻劣化与温升互为正反馈（发热→氧化→接触电阻增大→更热），这是"接头过热"类隐患按小时~天尺度演化的物理基础。

### 2.4 局部放电与带电检测判据

1. **局放量的法定计量**：GB/T 7354-2018《高电压试验技术 局部放电测量》（现行，2018-09-17 发布 / 2019-04-01 实施，经 openstd 实测确认；采标 IEC 60270，代替 GB/T 7354-2003）规定以**视在电荷量 q（单位 pC）**表征局放强度，测量系统需经方波校准溯源。【R36】【标准条文；代替关系经检索多源一致，标准页因版权不提供在线阅读，逐条引用前待核】
2. **开关柜带电检测（TEV 法）**：Q/GDW 11060-2013《交流金属封闭开关设备暂态地电压局部放电带电测试技术现场应用导则》为开关柜暂态地电压（TEV）带电检测的企业标准依据。实际案例（110kV 变电站 35kV Ⅱ母 PT 开关柜局放故障，2016）所引判定分级：**TEV 相对值 ≤20dB 正常，>20dB 异常，达 30dB 严重**；该柜实测 TEV 44dB、超声 28dB，判定为缺陷并定位到母线仓 A 相支柱绝缘子沿面闪络。【R37】【企业标准判据，经案例文章转述】
3. **超声波法分级（同案例所引）**：**≤8dB 正常 / 8~15dB 异常 / >15dB 缺陷**。【R37】
4. **多口径并存是常态**：超声"正常"阈值另见 ≤6dB 口径，单位有 dB、dBμV、dBmV 等不同标注；故业内通行做法是**绝对值判据 + 横向比较（同室相邻柜比较，差值显著如 ≥6dB 视为异常迹象）+ 纵向趋势（与历史检测值比较）三法并用**，TEV 尤其强调横向+纵向趋势判断，单点绝对值不足为凭。【R37】【工程惯例；"6dB"口径未定位到规程原文——待核】
5. **种子勘误**：种子材料将 Q/GDW 11063-2013 与 11060 并列为开关柜带电检测判据标准。检索显示 **Q/GDW 11063-2013 实为《暂态地电压局部放电检测仪（器）技术规范》**（检测仪器规范，非现场应用导则，更非超声导则）；对应"超声波"侧的是 Q/GDW 11061 系（名称与年代待核）。【R38】【待核——两份企业标准名称仅经检索与仪器厂商资料转述确认，未见官方文本】

### 2.5 直流系统（操作电源）判据

1. 直流操作电源标称电压：专供控制负荷宜 110V，专供动力负荷宜 220V，合并供电采用 220V（DL/T 5044 系规定）。直流系统正负极对地绝缘下降是典型隐患：一点接地只告警不跳闸，但若发展成**两点接地**，可能造成直流短路、熔断器熔断、开关误动或保护拒动。【R41】
2. **绝缘下降告警整定**：常见工程惯例为 **220V 系统约 25kΩ、110V 系统约 15kΩ** 时告警。【R41】【工程惯例；未定位到明确条文】另有资料按 GB/T 19826-2014 给出 **110V <25kΩ、220V <50kΩ** 的口径——两套数值并存冲突，装置技术条件标准为 DL/T 1392-2014《直流电源系统绝缘监测装置技术条件》（装置应在绝缘电阻低于设定值时可靠报警）。【R42】【待核——GB/T 19826 与 DL/T 1392 原文数值均未打开核对，DSL 默认值建议取 25/15kΩ 并强制携带 source_type=ENGINEERING 标签】

### 2.6 小电流接地与保护判据

1. **单相接地特征**：中性点非有效接地系统发生单相（金属性）接地时，故障相对地电压降为 0，两个非故障相对地电压升高至线电压（即 **√3 倍**相电压），三个线电压仍对称，不影响三相用户供电。【R45】
2. **带故障运行时间**：系统可短时带单相接地继续运行，**一般不超过 2 小时**，期间应尽快选线、定位、转移负荷；不能长期运行的原因是非故障相绝缘长期承受线电压，易在绝缘薄弱处引发第二点接地形成相间短路。【R44】【运行规程与教材通行惯例；"2 小时"未定位到现行国标逐字条文——待核】
3. **选线与过渡电阻**：小电流接地选线装置应对带过渡电阻的接地故障具备检测能力，文献、专利与装置验证中**300Ω 是常用的检测能力验证阈值**（过渡电阻超过该量级时稳态零序特征显著变弱）。种子材料将"选线 ≤300Ω"归于 GB/T 14285-2023，**本卷未能在该标准中定位到对应条文**。【R43】【待核——300Ω 暂按"文献与技术条件常用阈值（工程惯例）"处理】
4. **继电保护总纲**：GB/T 14285-2023《继电保护和安全自动装置技术规程》（现行，2023-11-27 发布 / 2024-03-01 实施，代替 2006 版，经 openstd 实测确认）是保护配置（含中性点非有效接地系统的单相接地检测/选线装置配置）的顶层依据，具体条款应在 DSL 保护模型定稿前对照原文核读。【R43】【标准条文；细则待核】

### 2.7 事件演化链与反事故措施体系

**四阶段演化链**：隐患（潜在缺陷/劣化趋势，如受潮、接触电阻增大、绝缘缓慢下降）→ 异常（判据越限但未成障碍，如 TEV >20dB、油温持续逼近 85℃）→ 告警（装置发出声光/遥信告警，如温控器 130℃ 报警、直流绝缘低于整定值）→ 事故（设备损坏或失电，如沿面闪络短路、两点接地误跳、母线失压）。该链与行业两套管理体系衔接：

- **缺陷分级管理**：设备缺陷按危急/严重/一般三档定级、定处理时限——对应 DSL 事件模型中的 severity 字段（企业规程体系，条文号待核）。【R63】
- **反事故措施**：
  - 国家能源局《防止电力生产事故的二十五项重点要求》——**现行版为 2023 版（国能发安全〔2023〕22号，2023-03-09 发布，修订代替国能安全〔2014〕161 号 2014 版）**，经能源局官方公开页实测确认；种子材料只提 2014 版，建模引用时应更新为 2023 版。【R64】【政策文件】
  - 《国家电网有限公司十八项电网重大反事故措施》2018 修订版（国家电网设备〔2018〕979 号，2018-11-09 印发，全文 18 章，含防止开关柜/变压器/直流系统/继电保护等设备损坏事故的专项条款）——企业反措体系，是"隐患→事故"各环节预防措施的条款来源。【R63】【政策文件；文号/日期与 18 章结构已由安全规程域卷经同一文件 PDF（R63）全文提取核验】

事件生成器含义：每个注入事件应携带 stage 序列（各阶段可停留或跳越）、每阶段的检测通道（遥测越限 / 遥信变位 / 带电检测 / 巡视发现）与对应反措条款引用，使"人机对比"练习能评估 agent 是否在正确阶段以正确通道发现演化。

### 2.8 IEC 61850 信息建模与遥测口径

1. **五层信息模型**：Server → Logical Device（LD）→ Logical Node（LN）→ Data Object（DO）→ Data Attribute（DA）。LN 由 IEC 61850-7-4 标准化命名（MMXU=测量单元、XCBR=断路器、CSWI=开关控制、PTOC=定时限/反时限过流保护、PTUV=低压保护），客户端无需厂商点表即可浏览陌生设备；属性按功能约束 FC 分组（ST 状态 / MX 测量 / CO 控制 / CF 配置 / SP 定值 / DC 描述），寻址形如 `FDR1LD0/MMXU1.TotW.mag.f`、`MMXU1.A.phsA.cVal.mag.f`。【R48】【国际标准】
2. **测点三元组 stVal + q + t**：每个状态/测量值携带品质位 q（有效性 good/invalid/questionable、oldData、来源 substituted、test 测试标志、operatorBlocked）与时标 t（UTC，带时钟故障/失步品质）。品质位不是可选项：处于试验模式的装置可能发出正常 stVal 但 q.test 置位，丢弃 q 的网关会把测试值当真实值转发。【R48】【国际标准】
3. **数据集与报告控制块**：报告按数据集发送，报告控制块分**缓冲型 BRCB**（客户端断线期间保留事件，重连按 EntryID 续传，缓冲溢出置 BufOvfl 标志需总召唤重建）与**非缓冲型 URCB**（断线期间事件丢弃）；触发条件 TrgOps 可选 dchg/qchg/dupd/IntgPd/GI，BufTm 控制发送前聚合时间。这一对语义直接映射 DSL 事件系统："缓冲=告警不丢，非缓冲=遥测流"。【R48】【国际标准】
4. **控制模型**：DO 的 ctlModel 属性区分 direct（直接控制）与 SBO（select-before-operate，选择-执行两步）及其普通/增强安全级（IEC 61850-7-2），是断路器等可控设备在 DSL 中操作语义的原型；枚举细节以 7-2 原文为准。【R48】【国际标准；五枚举名称细节待核】
5. **开源参照实现**：libiec61850（GPLv3，C99，MMS/GOOSE/SV + 缓冲/非缓冲报告、数据集动态创建、在线数据模型浏览）可作园区配电 DSL 模拟器报文通道与数据模型的参照实现。【R49】【工具项目，GitHub 实测可达】
6. **遥测口径纪律**：模拟器产生的"坏数据"（通信中断、传感器故障、时钟失步）必须以品质位+停走时标表达，**禁止删点或伪造数值**——这与真实 SCADA 一致，也保证人机对比中 agent 能学会"用品质位而非数据段判断数据可用性"。【R48】

## 3. 常见异常与故障现象（设备域事件库蓝本）

每条按「隐患→异常→告警→事故」给出演化、时间尺度与检测通道，供事件生成器直接参数化。

1. **开关柜局放劣化（绝缘受潮/污秽）**
   隐患：柜内凝露、绝缘子积污（发现通道：巡检/环境监测）→ 异常：TEV 相对值 >20dB、超声 >8dB（带电检测）→ 告警：TEV >30dB 或超声 >15dB、 audible 放电异音 → 事故：沿面闪络→相间短路→母线失压（ms 级突变）。
   时间尺度：隐患期数周~数月，闪络瞬间完成。实例：35kV PT 柜 A 相支柱绝缘子受潮积污沿面闪络，TEV 44dB / 超声 28dB，清扫更换消缺。【R37】
2. **接头/触头过热（接触电阻劣化）**
   隐患：安装力矩不足、氧化膜（红外测温趋势）→ 异常：温升逼近限值（65K 档，环温 40℃ 基准）→ 告警：红外/无线测温越限告警 → 事故：熔焊、拉弧短路（小时~天尺度演化，可被时间加速压缩）。
3. **干变超温**
   隐患：通风失效、长期过载、风机故障 → 异常：绕组温度持续在 100℃ 以上（风机常转）→ 告警：130℃ 超温报警 → 事故：150℃ 跳闸，未跳则绝缘热老化加速（F 级极限 155℃）。
   四点整定为厂家惯例，逐台设备可配置。【R40】
4. **油变油温异常**
   隐患：冷却器脏堵/全停、过载 → 异常：顶层油温经常超过 85℃（ONAN/ONAF 表值 95℃）→ 告警：85℃ 报警（惯例）→ 事故：105℃ 跳闸（惯例）或冷却系统故障油温骤升。【R39】
5. **10kV 单相接地**
   异常即告警：接地告警（零序电压升高、非故障相 ×√3）→ 处置窗口 ≤2h（惯例）：选线、定位、倒负荷 → 事故：超时或发展成两点接地→相间短路跳闸。DSL 应把"2h 窗口"做成带过渡电阻参数的故障注入场景。【R44】【R45】
6. **直流系统绝缘下降**
   隐患：电缆受潮/破损、端子箱进水 → 异常：对地绝缘电阻缓降（趋势）→ 告警：低于整定值（惯例 220V/25kΩ、110V/15kΩ）一点接地 → 事故：第二点接地→误跳开关或保护拒动（随机突变，仿真可按概率注入）。【R41】【R42】
7. **谐波超标（DER 与电力电子负荷）**
   隐患：充电桩/UPS/光伏逆变器群投入 → 异常：THDu 逼近限值（0.38kV 5%、10kV 4%）→ 告警：超标越限 → 事故：电容器过流鼓肚、谐振、敏感负荷脱扣。负荷构成变化（充电桩占用率）是"正常营业"事件的最常见来源。【R32】
8. **三相不平衡**
   隐患：单相负荷分配不均 → 异常：负序不平衡度逼近 2% → 告警：持续 >2% 或短时 >4% → 事故：低压电机发热、变压器降容。营业时段单相负荷投切属"正常营业"事件模板。【R33】
9. **电压偏差越限**
   隐患：无功补偿投切失当、分接头位置不当、光伏中午反送抬压 → 异常：偏差逼近 ±7%（10kV）/ +7%-10%（220V）→ 告警：越限 → 事故：敏感设备脱扣（少见，多为持续合格率劣化问题）。【R31】
10. **频率偏差**：大电网运行中园区侧基本不触发（±0.2Hz），但**孤岛/柴发后备切换**场景中频率质量取决于本地调速，事件生成器应在孤岛场景放宽至 ±0.5Hz 档建模。【R34】
11. **断路器操作异常（机构/控制回路）**
   隐患：储能电机/线圈劣化 → 异常：储能超时、操动机构响应变慢（遥信时标序列可判）→ 告警：储能不足/控制回路断线告警 → 事故：拒动使故障切除失败（与保护配合的联锁场景）。控制语义按 direct/SBO 建模。【R48】
12. **"管理变化"类事件（非故障，事件生成器正常营业模块）**
    运行方式调整（母联合/分、双路切换、柴发月度试机）、定值单变更（保护定值下发）、检修计划（设备退出/转检修态）、DER 出力计划（光伏午峰、储能充放策略）。此类事件不越限，但改变判据上下文（如检修态设备的告警应被抑制、试机时柴发短时承载），DSL 需要事件-判据联动：事件改变运行方式字段 → 判据集合随之切换。

## 4. 对 DSL 与仿真的含义

### 4.1 总则：判据的来源标签与确定性

每个阈值参数必须携带 `source_type` 字段，取值域固定：

```text
source_type ∈ { GB_STANDARD      // 国标条文（可执行判据）
              , DL_STD           // 行标/企标条文（Q/GDW、DL/T）
              , POLICY           // 政策/反措文件（十八项反措、二十五项反措）
              , ENGINEERING      // 工程惯例（无明确条文）
              , VENDOR_DEFAULT   // 厂家默认（逐台可改）
              }
```

理由：本卷核实即发现直流绝缘两套口径、Q/GDW 11063 名称错置、反措版本过期三处种子偏差；来源标签让判据在专家审查与现场落地时可分级信任。仿真判分时，`GB_STANDARD/DL_STD` 类判据可硬判，`ENGINEERING/VENDOR_DEFAULT` 类判据应允许 per-asset 覆盖。

### 4.3 仿真判分与人机对比要点

1. **时间尺度分层**：保护动作（ms~s）与热/绝缘演化（h~月）差 9 个数量级，DSL 应支持双速时间轴：故障注入用实时仿真，隐患演化用加速因子（如 1s=1h），判分关注 agent 是否在"正确阶段"干预而非动作速度。
2. **判据置信分级**：`source_type` 决定判分容差——国标限值越限即为错；惯例值越限只扣结构分（"发现趋势"得分，"报错数值"容忍）。
3. **横向比较场景**：TEV/超声类判据必须生成"整排柜背景值"，否则横向判读无法练习；建议模拟器给同室各柜注入背景 dB 值+疑似柜偏移。
4. **管理事件与判据联动**：检修态屏蔽告警、孤岛态放宽频率限值、定值单变更切换保护定值——这三类联动是"正常营业与管理变化"事件生成器的核心逻辑，全部可由 4.2 参数表的 per-asset 覆盖机制承载。
